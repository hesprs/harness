# OpenCode Sub-agent Resume Plugin

Makes sub-agents possible to be resumed by the main agent in OpenCode.

## Commands

- `bun --filter=@hesprs/opencode-subagent-resume run build` build plugin
- `bun --filter=@hesprs/opencode-subagent-resume lint` format and fix fixable lint errors (must run before `check`)
- `bun --filter=@hesprs/opencode-subagent-resume check` check types, format and lint
